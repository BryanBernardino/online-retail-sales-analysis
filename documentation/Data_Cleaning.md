# Data Cleaning

## Overview

As part of the **Tata Data Visualisation: Empowering Business with Effective Insights** virtual experience on **Forage**, the dataset was cleaned and transformed using Power Query before visualization.

---

## Data Preparation

The following data cleaning steps were performed:

- Removed cancelled transactions
- Removed duplicate records
- Checked for missing values
- Corrected data types
- Removed invalid quantities
- Created calculated revenue fields
- Validated transaction records

---

## Data Transformation

Power Query was used to:

- Import the dataset
- Clean and transform raw sales data
- Prepare the data model
- Optimize the dataset for dashboard reporting

These transformations ensured accurate calculations and reliable visualizations.
